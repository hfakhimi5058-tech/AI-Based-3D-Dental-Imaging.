AI-Based 3D Dental Imaging and Quantitative Analysis of Dental Structures

Overview

This research project integrates dental imaging, artificial intelligence, 3D image analysis, segmentation, and quantitative analysis of dental structures.

The project aims to develop a reproducible computational workflow for analyzing 3D dental imaging data and exploring AI-assisted methods for dental and biomaterials research.

Research Areas

- Dental imaging
- 3D image segmentation
- Artificial intelligence and machine learning
- Quantitative image analysis
- Dental structures and biomaterials
- Oral and dental research

Planned Workflow

1. 3D dental image preprocessing
2. Tooth and dental structure segmentation
3. AI-assisted image analysis
4. Quantitative measurement of dental structures
5. Visualization and statistical analysis
6. Reproducible research workflow

Dataset

The project will initially use publicly available dental imaging datasets, including ToothFairy2.

Large imaging files and model checkpoints will not be stored directly in this repository.

Tools and Technologies

- Python
- Google Colab
- PyTorch
- nnU-Net
- ToothSeg
- SimpleITK
- NumPy
- Pandas
- Matplotlib

Project Status

🚧 In development

The initial stage focuses on establishing the preprocessing, segmentation, and quantitative analysis pipeline.

Future Directions

Potential future extensions include:

- AI-based dental structure segmentation
- 3D quantitative analysis
- Automated morphological measurements
- Integration with dental biomaterials research
- AI-assisted analysis of oral and dental imaging
- Reproducible research pipelines
